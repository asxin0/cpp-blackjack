# Blackjack Console Project - CPP
Console blackjack game made while learning C++. This is my first programming project and first GitHub repository.

## Features

- Hit, stand, double down, and split mechanics
- Blackjack payout system (3:2)
- Bust, push, win, and loss detection
- Automatic ace value conversion
- Hidden dealer hole card
- Multiple playable hands after splitting
- Weighted random card generation
- Simulated blackjack shoe system
- Automatic reshuffling with cut card logic
- Multiple betting tables with different minimum bets
- Persistent save/load system
- Daily reward system
- Modular multi-file project structure

## Technologies

- C++
- Visual Studio
- STL

## Possible Future Improvements

- Inusrance bets
